# Third-party assets in `shader-object/assets`

Bundled so the examples run on a clean checkout with nothing to source. Both
licences below are commercial-friendly; the CC-BY ones require the attribution
recorded here to travel with any redistribution.

## Fox.glb

From the [Khronos glTF Sample Assets](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox)
collection. A skinned, textured model with three animation cycles — Survey,
Walk and Run — driving one shared skeleton, which makes it a good demonstration
of seeking a single clip rather than playing all of them.

- Model: © 2014 PixelMannen — [CC0 1.0 Universal](https://creativecommons.org/publicdomain/zero/1.0/legalcode)

- glTF conversion: © 2017 @AsoboStudio and @scurest — [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/legalcode)
